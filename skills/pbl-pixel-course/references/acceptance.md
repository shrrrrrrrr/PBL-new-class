# 一致性验收

## 小样先于批量

按实际显示尺寸与包内同类锚点并排：

| 维度 | 通过标准 |
| --- | --- |
| 颗粒 | 大方块/阶梯清楚，无平滑3D、写实、碎噪点 |
| 比例 | 同组平台大小、视角、光源和留边一致，不挡站位 |
| 题材 | 看出课时器材/活动，理论/实践可区分，不是通用空间站换名 |
| 色板 | 公共深蓝/奶油不漂移，少量辅色，文字层可读 |
| 透明 | 真alpha，无白黑底/棋盘/毛边，浅深底都检查 |
| 分层 | 标签/状态/角色/连线不烘焙进图 |
| 字体 | ChillReunion实际加载，无合成粗斜体或意外系统字 |

前三项明显不符或伪透明/随机文字就重做，不用平均分掩盖。脚本不判断艺术风格

## 页面

- 同屏对照桌面/平板/手机的场景、侧栏、面板、实验封面；长标题不溢出
- 查看全地图：顺序正确、无连线交叉/重叠，hover锚点不动，页尾无巨大空画布
- 关卡/徽章/头像为按钮，鼠标/键盘/触摸可开中央详情，焦点与返回正确
- 机器人可点击、拖动、拖后再点；滚动不移位，弹窗遮罩不穿透
- hover/press/focus一致，disabled/loading不弹起，reduced-motion仍有可见反馈
- 图失败仍可读可操作，登录短屏/键盘可提交，教师失败或取消离开保原输入和选件
- 风格不覆盖真实权限/完成/数据；账号奖励不变课程私有账本

## 交付边界

提供brief、图稿、提示词、清单、来源/许可、页面截图及已验/未验项。模拟视口不冒充真机，单模型成功不冒充跨模型复现。空白图/整页生图不冒充完成前端
