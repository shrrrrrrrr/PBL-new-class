# 前端与课程接入

复用目标项目已有组件、令牌、资源管线和API。[pbl-pixel.css](../assets/pbl-pixel.css)是独立作用域示例；映射进现有React/Ant Design，不全局覆盖另一应用body/button

## 范围

- 平台选课展示后台授予的已发布有效课程，不加学生自助选课；我的/签到/金币/徽章为账号统一
- 课程内部关卡地图、实验室、成长档案独立；数量与章节按真实教学结构，不把旧十关复制为所有课程规则
- 主题来自受控配置，不按名字/ID猜。原平台campus/voyage之外的新主题须按授权扩展前后端受控映射，不能填任意字符串就称已支持
- 管理员全局、负责执行导师维护负责课程、普通教师只读，回放上传管理员专用。菜单隐藏不是授权
- 保持回顾→卡片/练习→报告/反思→评审及作品独立提交；技能不定义新锁关、分数或金币规则，不以点击判完成

## 地图

1. 分离场景、节点按钮、角色、SVG连线及标题/状态/详情；序号和可访问名称由DOM给出
2. 按真实顺序蛇形/交错铺展，行间留转弯空间，只连相邻节点，无跨行折返或重复重叠边
3. 初次、图片/字体加载、ResizeObserver和布局变化后测未经hover变换的稳定站位锚点；浅金虚线C/Q曲线在节点后面，不穿标签
4. 每图配置landingAnchor（0–1归一化），角色/连线共享落点。当前/选中/完成/未知分别表达
5. 中央详情有真实名称、安排、状态、说明、可得徽章、进入课时；无常驻右栏，失效/未提供内容说明原因
6. 手机纵向交错重排重算路线，按内容收尾，未知灰轮廓加网页锁/问号，不等于已存在教材

## 阅读、实验、维护

侧栏也有课程场景；正文/表单浅底稳定，场景与透明阅读层分离。实验目录各项有学科相关封面/alt/裁切；指标与图表真实，不为美术改仿真数据

教师维护共用学生显示组件，对应区域编辑/上传；预览不读具体学生答案/进度，学习提交禁用。文字/队列独立保护，保存正文不能清除待上传dirty；冲突/失败保输入，准备状态/卡片发布/课程发布分别说明

机器人视口Portal，不随正文滚动；小位移阈值区分单击/拖动，pointercancel和拖后仍能再点击。空白收起浮窗、Escape/关闭/回焦/手机键盘避让；顶端返回sticky，不把普通空白点击当后退

## 文案与媒体

教材/课程名/绑定来自真实配置；菜单与系统提示用独立可审阅ID，空串/显式隐藏不补回小字。仅完整显示块末尾句号省略，不改保存值、输入、内部标点、代码或网址

图片带宽高/alt/srcset/sizes和失败降级，首屏按需eager其余lazy，不全载母版。私有教材图片/附件沿鉴权接口，不公开uploads。加载/空/保存/失败/权限/离开确认复用同风格

桌面/平板/手机/短屏均验，触摸无需hover；弹窗锁背景、约束焦点、Escape/空白关闭和回焦，机器人不穿透。持续场景/机器人动画不默认新增，既有一次性获章反馈尊重减少运动
